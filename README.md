## 📖 About

This repository contains my personal study notes and Packet Tracer labs created while studying for the **Cisco Certified Network Associate (CCNA 200-301)** certification.

The notes are designed to be **concise, beginner-friendly, and easy to review**. Rather than copying lecture transcripts, each lesson focuses on defining key concepts using short explanations and simple examples.

The labs reinforce the concepts through hands-on practice in **Cisco Packet Tracer**.

> **Note:** These notes are based on Jeremy's IT Lab CCNA course and are intended to complement the video lessons, not replace them.
